# 💫 About Me:
Hi, I’m Ahmed, a Computer Science student at the University of Sheffield and an AI/ML enthusiast. I’m building toward a career in data science and machine learning, with a potential Masters down the line.

I work mainly in Python, using TensorFlow, Keras, Hugging Face Transformers, and OpenCV. Recent projects include:

NLP sentiment analysis on ~41,000 COVID-19 tweets, using DistilBERT, which outperformed LSTM and RNN baselines
Fire and smoke detection with a custom-trained YOLO model
Vehicle tracking and counting with a centroid-based counter I built when the built-in tracker fell short

Outside of coding, I’m into football, gaming, and cooking.
